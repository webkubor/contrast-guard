# 风格库（Style Anchors）—— 八种可选视觉风格

> **这份文档是「选哪种风格」的菜单，不是「只能用这一种」的枷锁。**
>
> 以下是可选视觉配方，具体字体、色值、尺寸和材质是探索起点，不能覆盖品牌、既定稿或项目 token。没有默认风格，也不要求从菜单中选一个。验收遵循[评审标准](https://github.com/webkubor/frontend-contrast-guard/blob/main/../)，适用 WCAG 门槛与项目约束需单独说明。

## 一、使用方式

从产品任务、受众、内容密度和参考来源选择或组合方向，先验证小样，再决定哪些 token 与交互进入项目契约。真实内容与适用的键盘、焦点、错误状态仍需检查；计量是证据，不是风格分数。

## 二、八种风格

### 1. Swiss（瑞士国际主义）
**表面**：纯白 `#FFFFFF` 或中性 `#F7F7F8`。**字体**：Akzidenz-Grotesk、Helvetica Neue 或 Söhne——无衬线做标题与正文，同一家族。**强调色**：Swiss Red `#E4002B`、International Orange `#FF4F00` 或 Yves Klein Blue `#002FA7`——取一个，用得刻意。**结构**：可见网格线或 1px 细线分隔。左对齐排版；非对称平衡。数字作为构图元素（日期、页码用窄体无衬线）。
**气质**：克制、理性、精确。适合作品集、档案、工具站、数据产品。

### 2. Industrial（工业控制台）
**表面**：纯黑 `#000000` 或暖黑 `#0B0C0A`。**字体**：IBM Plex Mono、JetBrains Mono 或 Berkeley Mono——标题与正文全等宽。**信号色**：一个语义色——绿 `#00E676`、红 `#FF3B30`、琥珀 `#FFB800` 或酸绿 `#C6FF4A`。**结构**：扁平；1px 边框代替阴影。数字用 `font-variant-numeric: tabular-nums`。
**气质**：硬核、终端感、运维气质。适合开发者工具、监控面板、技术专题。

### 3. Brutalist（野兽派）
**表面**：纯主色或反色——`#FF0000`、`#0000FF`、`#FFFF00`、`#000000`、`#FFFFFF`。取 2~3 个，平权竞争。**字体**：只用系统字体——Times New Roman、Helvetica、Courier、Arial、system-ui。刻意混用。**阴影**：硬偏移、无模糊——`box-shadow: 8px 8px 0 #000`。**控件**：原生浏览器——未样式化 `<button>`、默认 `<select>`、保持蓝色的下划线链接。边距压到最紧；文字顶天立地。
**气质**：反精致、粗粝、有主张。适合创意工作室、实验性发布、独立刊物。

### 4. Aurora Maximalism（极光繁复）
**表面**：深色高饱和渐变——`linear-gradient` 或 `conic-gradient` 走紫 `#5D34D0` → 洋红 `#FF006E` → 青 `#00F0FF`，或 `#3B82F6 → #A855F7 → #EC4899`。**字体**：Inter Variable、PP Neue Machina 或 Sharp Grotesk 做超大标题（15–25vw）。**纹理**：网格渐变作为主表面特征；强调色发光晕影 `0 0 20px <accent>`。**动效**：弹簧物理编排、滚动视差。
**气质**：未来感、张力、视觉冲击。适合 AI 产品、创意发布、音乐、潮流品牌。

### 5. Chaotic Maximalism（混乱繁复）
**表面**：冲突色板——粉彩 *与* 霓虹同处一画。热粉 `#FF71CE` + 酸黄 `#DFFF00` + 青 `#00FFFF` + 任意第三色。**字体**：刻意碰撞的混排——同页 3+ 个不同气质的字族。**纹理**：每个表面都有图案（波浪、圆点、锯齿、棋盘——SVG 或 `repeating-linear-gradient`）。超大标题撞上繁杂底。
**气质**：疯、张力、反秩序。适合艺术展、音乐节、亚文化内容。

### 6. Retro-Futuristic（复古未来）
**表面**：纯黑 `#0A0014` 或深海军黑。**字体**：年代专属——VT323（CRT）、Orbitron（合成波）、Space Mono（赛博朋克）、Monoton（迈阿密霓虹）、Press Start 2P（街机）、IBM Plex Mono（终端）。**强调色**：霓虹对——洋红 `#FF006E` + 青 `#00FFFF`（合成波）或磷光绿 `#00FF41` + 琥珀 `#FFB000`（终端）。**纹理**：CRT 扫描线（`::before` `repeating-linear-gradient` 叠加）或色差（`text-shadow: 2px 0 #FF0000, -2px 0 #00FFFF`），或两者都有。辉光为可选表达。
**气质**：80 年代科幻、赛博、终端复古。适合游戏、硬件、复古科技专题。

### 7. Organic（东方自然）
**表面**：大地色——鼠尾草绿 `#8B9D83`、陶土 `#B08B6E`、赤陶 `#C66B3D`、赭石 `#C08E3A`、苔绿 `#606C38`。需要浅色面时：沙色 `#E8DCC7` 或燕麦色 `#D4B895`。**字体**：人文衬线（Freight、Caslon、Fraunces）或暖几何无衬线（Greycliff、Epilogue、Recoleta）。**结构**：圆角 16–32px。**纹理**：1–3% 颗粒（SVG feTurbulence）。**动效**：缓动 300–500ms，hero 元素呼吸式动画。
**气质**：温润、东方、留白呼吸。适合生活方式、茶器/器物、慢内容。

### 8. Lo-Fi（低保真纸感）
**表面**：纸黄 `#E8E0C0` 或 `#EDE4CF`——比奶油更饱和。**字体**：同页混用系统字体（Times + Helvetica + Courier 刻意碰撞）。**结构**：元素离轴旋转 2–8°（`transform: rotate`）。**纹理**：图像上半调点过渡（SVG pattern 或 `radial-gradient` 平铺）；Risograph 套印偏移（2–4px RGB 通道偏移 `text-shadow: 3px 0 #FF006E, -3px 0 #00FFCC`）。SVG 订书钉、胶带、撕边元素。
**气质**：手作、印刷感、拙趣。适合手账、独立杂志、个人博客。

## 三、选定风格后的工作法

1. **背景**——识别用途、受众、领域、内容密度。一句话说清要解决什么问题。
2. **选风格**——按 brief 的气质选一个，或让 Agent 推荐并说明理由（一行）。不指定时先读取项目资产与参考，不推定默认风格。
3. **差异点**——定义一个风格内部的记忆点：标志性交互、字体姿态、布局母题或材质处理。一句话，可在渲染结果中看见。
4. **执行**——风格决定字体/色板/纹理；按项目 token、适用状态与内容契约执行。

---

## 四、交付自查

- **风格是否成立**——是主动选了风格，还是滑向了无特征的默认？
- **token 忠实**——渲染结果是否符合项目已选设计契约，例外是否有目的？
- **底线是否全过**——对比度达标？六态完备？无伪造数据与 filler？字号走阶梯？（用可用计量和浏览器证据核对）
- **差异点可见**——那个记忆点真的渲染出来了，还是只写在说明里？
