# award-creative-ui

Awwwards / Webby / FWA 获奖级创意 UI 研发手艺与门禁标准（CortexOS Skill）。

## 核心能力

1. **短板一票否决门禁**：Usability 30% 无障碍键盘焦点环、移动端手势等价性、`prefers-reduced-motion` 零眩晕保护、60FPS 帧率预算。
2. **实体触觉一致性**：Hover 悬停、Focus 轮廓与 `:active` 物理下压（scale 0.96~0.99）三态闭环，消除数字界面纸片漂浮感。
3. **4 步自检循环**：快照 → 门禁审计 → 针刺打磨 → 证据收敛。
