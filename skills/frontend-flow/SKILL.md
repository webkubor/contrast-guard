# Frontend Flow

读取 [完整 Flow](https://github.com/webkubor/frontend-contrast-guard/blob/main/docs/frontend-flow.md)，再按任务加载对应 skill。判定以 [评审标准](https://github.com/webkubor/frontend-contrast-guard/blob/main/docs/frontend-review-standard.md) 为准，工程方法见 [通用方法](https://github.com/webkubor/frontend-contrast-guard/blob/main/docs/frontend-engineering-methods.md)。

全局方法仅描述工作过程；项目品牌、组件库、域名、账号、环境和发布规则读取目标项目。不要将项目风格推广成全局要求，不在安装目录修改第二份规范。
